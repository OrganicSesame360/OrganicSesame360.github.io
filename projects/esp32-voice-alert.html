ESP32 Voice Alert Device

A small touchscreen device that waits for a signal and then speaks a custom voice message out loud.

Goal

Build a standalone device that receives a signal and announces a message by voice, with no computer needed once it is set up.

  • Learn how ESPHome turns a YAML file into working firmware
  • Connect the device to Home Assistant so it can be triggered remotely
  • Get clear, reliable speech from the built-in speaker

How it works

The device connects to Wi-Fi and to Home Assistant. When Home Assistant sends a trigger, the device plays the voice message through its speaker.

  1. Install ESPHome. This tool writes the firmware for the device from a simple text config.
  2. Flash the device. Plug it in over USB and upload the firmware.
  3. Add it to Home Assistant. The device shows up automatically once it is on Wi-Fi.
  4. Send a message. Trigger the voice alert from Home Assistant.
